# Sales-Customer-Dashboard

A multi-page Power BI dashboard built on the AdventureWorks dataset, analyzing $24.9M in revenue and 25K+ orders across 2020–2022. The report includes four pages — an executive summary with KPI cards and revenue trending, a geographic map view across countries, a product detail page with what-if price adjustment simulation and profit vs target gauges, and a customer segmentation page with income/occupation breakdowns. Built on a star schema with CSV tables, using DAX measures, Power Query transformations, drill-through navigation, and cross-filtering throughout.
